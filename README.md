#### Description:

McG"eye"ver of the Underworld is a website created as my CS50x final project. It showcases the research, development, and field-testing process behind custom-built paranormal investigation tools.

The website includes four main pages:

- **Home:** Introduces the brand and its purpose.
- **Meet the Maker:** Shares the maker's story and creative process.
- **The Workshop:** Displays projects and demonstrates interactive filtering by development status.
- **Contact:** Provides an inquiry form interface for questions and future collaborations.

### Technologies

- HTML for page structure and content.
- CSS for styling and responsive layouts.
- JavaScript for project filters, form validation, and the automatic copyright year.

### Design

The visual identity uses a gothic-inspired palette of burgundy, parchment, and antique gold, with an all-seeing-eye motif planned for the branding.

### How to Run

Open `index.html` in a web browser, or use a local development server to preview the website.
